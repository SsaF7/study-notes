# Библиотека конспектов

Когда пользователь просит «сделай конспект и добавь на сайт»:

1. Создай и проверь конспект по навыку `konspekt-iz-uchebnika`. Если навык не установлен в текущем агенте, используй его файл `C:/Users/Ssaf77/.agents/skills/konspekt-iz-uchebnika/SKILL.md` на этом ПК. Для публикации используй только проверенный готовый HTML или ZIP с `index.html` в корне и его ресурсами.
2. Запусти `python scripts/import_note.py <файл> --subject "<предмет>" --slug <slug>`. Выбери существующий предмет, если подходит, и короткий постоянный идентификатор из строчных латинских букв, цифр и дефисов.
3. Выполни `python -m unittest discover -s scripts -p "test_*.py"` и `python scripts/build.py`. Проверь открытие конспекта и один поисковый запрос по его тексту.
4. Добавь в коммит только новый каталог `notes/<slug>/`. Отправь коммит в `main` через авторизованный Git. При конфликте синхронизируйся с удалённой веткой, повтори проверки и отправь изменения без принудительной перезаписи.
5. Дождись завершения **Publish library** в GitHub Actions для этого коммита. Проверь открытие страницы с `?note=<slug>` по опубликованной ссылке. Если публикация недоступна, сообщи, что уже добавлено локально и какой шаг заблокирован.

Файлы внутри `notes/<slug>/content/` публикуются и могут исполнять JavaScript. Добавляй только проверенные материалы, предназначенные для общего доступа. Исходники учебников, рабочие файлы и данные доступа остаются локальными.
