# Библиотека конспектов

## Локальный запуск

Нужен Python 3.11 или новее. Из папки проекта выполни:

```powershell
python scripts/build.py
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Открой [локальную библиотеку](http://127.0.0.1:8000/).

## Новый конспект

```powershell
python scripts/import_note.py "outputs/Новый конспект.html" --subject "Физиология" --slug new-topic
python scripts/build.py
```

Также поддерживается ZIP с `index.html` в корне. Импортирует только UTF-8 HTML и локальные ресурсы страницы. Известный набор файлов повторно не добавляется. Уже занятый идентификатор сохраняет прежний конспект. Ссылка на новый материал имеет вид `?note=new-topic`. Порядок работы для ИИ описан в `AGENTS.md`.

## Первая публикация

1. Создай отдельный пустой репозиторий GitHub для этой библиотеки. На бесплатном плане GitHub Pages требует публичный репозиторий.
2. Инициализируй Git в этой папке, привяжи репозиторий как `origin` и отправь ветку `main`.
3. В настройках репозитория открой **Pages → Build and deployment → Source** и выбери **GitHub Actions**. Если первый запуск уже завершился ошибкой из-за отсутствующей настройки, запусти **Publish library** повторно из вкладки **Actions**.
4. Возьми публичный адрес из результата шага deploy. После первого запуска новые коммиты в `main` обновляют этот адрес автоматически.

Перед коммитом проверь список файлов. Готовые конспекты из `notes/` попадут в публичный сайт. Исходные HTML и ZIP в корне, исходные PDF и папка `outputs/` исключены из Git.
